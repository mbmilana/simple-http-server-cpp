# HTTP-сервер на C++

Простой HTTP-сервер с использованием сокетов Berkeley. Без сторонних библиотек.

* Обработка GET-запросов
* Отличие корневого пути `/` : ответ `200 OK` от всех остальных: ответ `404 Not Found`
* Поддержка IPv4

## Требования

- Операционная система Linux / WSL (Windows Subsystem for Linux)
- Компилятор с поддержкой C++11 (g++, clang++)

## Компиляция и запуск
g++ server.cpp -o server\
./server\
